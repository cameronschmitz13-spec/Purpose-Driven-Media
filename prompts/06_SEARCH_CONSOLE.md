# Work Prompt — Search Console Review

Use after the verified Search Console property has populated meaningful data.

Review:
- homepage URL Inspection
- live test
- indexed/not-indexed state
- Google-selected canonical vs user canonical
- crawl state
- Pages/Indexing reasons
- sitemap status
- Core Web Vitals if available
- performance queries/pages once data exists

Separate:
A. confirmed issues
B. normal new-property delays
C. opportunities
D. items requiring more data

Do not treat an empty newly verified property as proof of failure.
