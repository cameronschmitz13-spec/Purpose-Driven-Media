# Work Prompt — Mobile Conversion UX

Read AGENTS.md.

Audit the homepage at common mobile widths.

Focus on:
- first viewport comprehension
- text size
- CTA prominence
- sample-report legibility
- tap targets
- excessive vertical space
- competing CTAs
- navigation friction
- layout shift
- performance-heavy visuals

Preferred persistent CTA after hero:
**Start My Visibility Screening**

Only use a sticky CTA if it does not obstruct content.

Make the smallest high-impact changes and test them.
