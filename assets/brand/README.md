# PDM Brand Assets

This directory is reserved for the canonical Purpose Driven Media brand artwork.

See `docs/BRAND.md` for usage rules, approved audience variants, exact copy, source dimensions, and sampled colors.

## Canonical filenames to use in this repository

When adding the supplied PNG originals, rename them to:

- `pdm-mark-primary.png` — compact gold-chevron + navy PDM mark
- `pdm-lockup-businesses.png`
- `pdm-lockup-organizations.png`
- `pdm-lockup-ministries.png`
- `pdm-lockup-nonprofits.png`

Do not replace these originals with AI-generated approximations.

## Preferred default

For the general PDM website, use:

`pdm-lockup-organizations.png`

For compact placements use:

`pdm-mark-primary.png`
