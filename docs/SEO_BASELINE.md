## Technical checks
- Homepage returns 200
- HTTPS canonical is correct
- fbclid/UTM variants canonicalize to the clean URL
- No accidental noindex
- robots.txt allows intended crawling
- sitemap.xml or sitemap index is valid
- Search Console live test succeeds
- structured data matches visible content
- mobile rendering is usable
